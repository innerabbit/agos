# AGOS

**AGOS is an autonomous agent framework for workflow automation.**

Build durable, permissioned agent workflows with graph-based execution, reusable capabilities, multi-agent orchestration, memory, approval gates, and observable recovery.

## Current MVP

Autonomous Research-to-Publish: fixture research → provenance → draft → claim review → explicit approval → idempotent Markdown artifact.

The current runtime is local and single-process. Distributed workers, external source connectors, and external publisher adapters are planned—not claimed as complete.
